## ルール

- ファイル名は `ref連番_分野_内容.md`（連番は3桁、通し番号）
- 論文の解説は `papers/paper連番_第1著者年_内容.md`（[papers/README.md](papers/README.md)）
- 図は `images/ref連番/` に置く。フォルダ名は英語
- ネットの画像はライセンスを確認して保存し、出典（作者・ライセンス・元URL）を必ず書く
- 数式は TeX で書く（行内は `$...$`、別行は `$$...$$`）
- 計算で作る図は `scripts/` の Python で生成し、mdにスクリプトへのリンクを書く

## 図の再生成

```bash
pip install matplotlib numpy
cd study/scripts
python make_ref002_figs.py
python make_ref003_figs.py
python make_ref004_figs.py
python make_ref004_figs2.py
python make_ref005_figs.py
python make_ref005_points.py
python make_ref005_dyn.py      # 動的コンプライアンス最小化（数分）
python make_ref007_figs.py

python make_ref008_multiobj.py   # 多目的最適化（約 1 分）
python make_paper001_figs.py
python make_paper001_stability.py
```

日本語フォントは `~/.fonts/meiryo.ttc` または Windows のフォント（`/mnt/c/Windows/Fonts/`）を自動で探す（[figstyle.py](scripts/figstyle.py)）。

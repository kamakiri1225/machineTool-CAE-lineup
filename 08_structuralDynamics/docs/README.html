docs — マルチフィジックス学習・検証ログ

工作機械（マシニングセンタ／NC旋盤）を題材に、オープンソースCAE・シミュレーションで どこまでできるかを実際に試して記録していく場所。 振動・熱の研究への接続は研究テーマ一覧（非公開）、権利化の検討は特許戦略（非公開）にまとめる。

命名規約

種別 形式 例
解析トライアル ana連番_ソフト名_内容.md ana001_CalculiX-FrontISTR_簡易工作機械の固有値解析.md
知識・調査メモ ref連番_分野_内容.md ref000_overview_オープンソースマルチフィジックス総覧.md（勉強ノートは ../study/ へ）
  • 連番は3桁ゼロ埋め、通し番号（ソフトごとにリセットしない）
  • 1ファイル = 1トライアル。失敗も残す（何が動かなかったかが資産）
  • 解析トライアルのmdには最低限これを書く：
    1. 目的（何を知りたいか／実機の何に対応するか）
    2. 環境（OS・バージョン・インストール方法）
    3. モデル（寸法・材料・境界条件・メッシュ）
    4. 実行コマンド
    5. 結果（数値・図）
    6. 妥当性チェック（理論式・文献値との比較）
    7. 詰まった点／次の課題
  • 図や画像は images/<ファイルの番号>/（例: images/ana001/）に置く。ネットの画像はライセンスを確認し、出典を必ず書く
  • 数式は TeX で書く（行内は $...$、別行は $$...$$）。図の中の数式も matplotlib の mathtext（TeX 記法）で書く
  • 入力ファイル・スクリプトは ../analysis/ana001_ccx_fistr_modal/ のように解析ごとのフォルダ（フォルダ名は英語）に置き、 mdからの相対リンクで参照する

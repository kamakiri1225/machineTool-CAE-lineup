# 002_multiPhysics — 工作機械 × オープンソース マルチフィジックス

工作機械（マシニングセンタ）を題材に、オープンソースの CAE でどこまでできるかを試していくプロジェクト。

| フォルダ | 中身 |
|---|---|
| [docs/](docs/README.md) | 解析の記録（`ana連番_ソフト名_内容.md`）と、ツール・設定の調査（`ref`） |
| [study/](study/README.md) | 工作機械の基礎知識の勉強ノート（論文解説は [study/papers/](study/papers/README.md)）（主軸テーパ、切削、固有振動数とゲイン、ばね剛性と減衰） |
| [analysis/](analysis/) | 解析の入力・スクリプト・結果（`ana連番_英語名/`）。共通ツールは `analysis/tools/` |

## ルール

- フォルダ名は英語。ファイル名は日本語でよい
- 数式は TeX（`$...$`、`$$...$$`）
- 各ページの先頭と末尾に「目次へ戻る・前・次」のリンクを付ける（[tools_nav.py](tools_nav.py) を実行すると付け直せる）
- ネットの画像はライセンスを確認し、出典を書く

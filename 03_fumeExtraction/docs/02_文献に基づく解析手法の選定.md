# レーザー加工ヒューム：文献に基づく解析手法の選定

調査日：2026-11-04

## 結論

今回の目的を「レーザー加工中・加工後に残る煙の濃度分布、漏出、排気による除去時間を調べる」とする。微細なヒュームが気流へ十分追従する条件では、**非定常の移流拡散方程式による濃度輸送を主解析**にする。粒径による差が必要なら粒径区分ごとに濃度方程式を解き、慣性・沈降・衝突が重要な粗い粒子には粒子追跡を併用する。

これは以下の文献と目的を照合した本件への工学的判断である。「粒子追跡が主流だから採用する」とは判断しない。材料、実際の粒径分布、装置寸法、噴流条件が未確定なので、現段階で唯一の手法を断定することもできない。

## 何を解くか

空気密度一定、粒子の滑りを無視する近似では、質量濃度 C [kg/m³] に対して次式を使う。

$$
\frac{\partial C}{\partial t}+\nabla\cdot(\mathbf{u}C)
=\nabla\cdot\left[\left(D_B+\frac{\nu_t}{Sc_t}\right)\nabla C\right]+S_C-R_C
$$

- u：空気の速度。煙の熱で上昇流が生じる場合は温度・浮力を含む流れから求める。
- D_B：粒径に応じたBrown拡散係数。気体成分の分子拡散係数をそのまま粒子へ使わない。
- ν_t / Sc_t：RANSでモデル化する乱流拡散。乱流Schmidt数は仮定値を明記して感度を確認する。
- S_C：加工部からの発生量・位置・時間履歴。加工停止後は発生を止めて残留濃度の減衰を計算する。残熱等で発生が続く場合はその履歴を反映する。
- R_C：必要に応じた除去項。壁面沈着は境界の沈着フラックスとして扱う方法もあり、二重計上しない。

粒径ごとに追従性や沈着が違う場合は C_i を複数解く。沈降等の滑り速度を輸送速度に追加するEuler的な方法もあり、スカラー輸送だから粒径依存性を一切表現できない、というわけではない。

受動スカラーの妥当性は、局所的なStokes数 St = τ_p / τ_flow が十分小さいか、沈降速度が対象流速に比べ十分小さいかで確認する。粒径だけで一律に区切らず、ノズル近傍の急加速や狭いすき間では別に確認する。微小粒子の緩和時間・拡散にはすべり補正も考慮する。

## 本件の実施順序と評価量

1. 加工機の囲い、給気・排気位置、流量、加工点、温度・残熱、横風を確認して流れ場を作る。上から吸う依頼なのか、既存run001の下引きテーブルなのかも形状条件として確認する。
2. まず非定常の濃度輸送で、発生中の漏出と加工停止後の残留を比較する。絶対発生量が不明なら規格化した同一発生源を使い、絶対濃度の予測とは区別する。
3. 領域内総量、排気口へ流出する量、他開口から漏れる量、沈着量の収支を積分する。排気への流出をフィルタでの最終捕集と同一視しない。
4. 同じ初期・発生条件で、吸引位置・流量による濃度低減と除去時間を比較する。濃度が初期値の10%や5%へ下がる時間などは比較指標であり、安全基準を意味しない。
5. 粒径別捕集や粗い粉じん・スパッタの付着が必要ならDPMを追加し、乱流分散、粒径分布、注入統計、沈着条件を確認する。凝集が重要なら粒径分布を輸送するモデルへ進む。
6. メッシュ・時間刻み依存性と質量収支を確認し、風速・濃度減衰等の実測と比較する。煙の見た目だけから質量濃度や粒径を決めない。

## 現在のrun001との関係

run001は熱浮力・実際のアシストガス流れ・乱流粒子分散を省略し、2–50 µmの粒子を定常場で追跡した予備解析である。これを実ヒュームの捕集率へ読み替えない。既存の流量感度計算は同モデルの比較として保存し、次段階の煙濃度解析では上記の手法を採用する。

実装の参考：[OpenFOAM scalarTransport](https://doc.openfoam.com/2306/tools/post-processing/function-objects/solvers/scalarTransport/)。標準機能の拡散係数・乱流拡散・発生源の設定を使用バージョンで確認する。固定速度場での濃度解析は予備比較に使えるが、熱浮力が支配的な場合は流れ場自体の見直しを先に行う。

03 オイラー–オイラー法と VOF の違い、VOF で固体連成はできるか

作成日：2026-11-04

1. 2 つの方法のちがい

気液の流れを解く代表的な方法が、今回使ったオイラー–オイラー法（chtMultiRegionTwoPhaseEulerFoam）と VOF 法（interFoam など）。

オイラー–オイラー法（今回） VOF 法
考え方 気相と液相を2 つの連続体として重ねる。1 つのセルの中に気と液が混ざって存在してよい 気と液を1 つの流体として解き、どこが液か（α = 1）を追う。界面をくっきり捉える
速度 相ごとに別々（ug、ul） 1 つ（気液で共通）
方程式の数 相ごとに質量・運動量・エネルギー（2 倍） 質量（α の輸送）・運動量・エネルギーを 1 組
相の間の力 抗力・揚力・仮想質量などのモデルが必要（液滴・気泡の径を仮定） 界面の表面張力だけ（形はメッシュで直接表す）
界面 ぼやける（α が 0〜1 の間で連続的に変わる） 鋭い（界面圧縮の工夫で 1〜3 セルの厚さに保つ）
メッシュ 粗くてもよい（液滴や気泡はセルより小さくてよい） 液膜・液柱の厚さより十分細かいセルが必要
向いているもの 噴霧・飛沫・気泡流・沸騰など、細かい粒・泡が多数ある流れ 液面・液柱・液膜・跳ね返りなど、界面の形そのものを見たい流れ
今回の加工エリアでは 20 mm の粗いメッシュでも動くが、液の柱がすぐ空気と混ざってぼやける 液の柱・ワーク上の液膜の形が見える。ただし液膜（数 mm）を表すには 1 mm 以下のセルが必要で、3 次元では重い

VOF の基礎式（interFoam 系）

\[ \frac{\partial \alpha}{\partial t} + \nabla\cdot(\alpha\mathbf{u}) + \nabla\cdot\big(\alpha(1-\alpha)\mathbf{u}_r\big) = 0 \]

\[ \frac{\partial (\rho\mathbf{u})}{\partial t} + \nabla\cdot(\rho\mathbf{u}\mathbf{u}) = -\nabla p + \nabla\cdot\boldsymbol{\tau} + \rho\mathbf{g} + \sigma\kappa\nabla\alpha, \qquad \rho = \alpha\rho_l + (1-\alpha)\rho_g \]

（第 3 項 ∇·(α(1−α)ur) は界面をくっきり保つための人工的な圧縮項、σκ∇α は表面張力）

オイラー–オイラー法の式は 01_… の「2.4 基礎式」。運動量の式が相ごとに 2 本あり、 その間を抗力などの相間力 Mk でつないでいる点が VOF との一番の違い。

2. VOF で固体との熱連成はできるか

できる。ただし、OpenFOAM の版によって違う。

版 VOF ＋ 固体の熱連成 方法
ESI 版 v2512（今回の run で使用） 標準のソルバにはない chtMultiRegionFoam の流体は単相、chtMultiRegionTwoPhaseEulerFoam はオイラー–オイラー法のみ
Foundation 版 OpenFOAM 13（このパソコンに /opt/openfoam13 で入っている） できる foamMultiRun で、流体領域に compressibleVoF、固体領域に solid のモジュールを割り当てる。例題 tutorials/multiRegion/CHT/VoFcoolingCylinder2D がある

OpenFOAM 13 の例題の設定（system/controlDict）：

regionSolvers
{
    fluid           compressibleVoF;    // 気液（VOF、圧縮性、エネルギー式あり）
    solid           solid;              // 固体の熱伝導
}

ESI 版でやる場合の回避策：

  1. 一方向の受け渡し（Geist ら 2026 の方法）：VOF（compressibleInterFoam）で壁の温度を固定して 熱伝達率を求め、その熱伝達率を固体の計算（solidFoam や FEM）の境界条件にする。 熱が時間をかけて伝わる工作機械の熱変形の計算は、この方法が現実的。
  2. 自作ソルバ：chtMultiRegionFoam の流体部分を interFoam 系に入れ替える（手間が大きい）。

3. 今回のクーラントの問題にどちらを使うか

見たいもの おすすめ
クーラントの液柱・液膜がワークのどこを濡らすか VOF（OpenFOAM 13 の compressibleVoF ＋ solid）。ワーク周りを 1 mm 程度に細かくする
飛び散った飛沫やミストが加工エリア全体にどう広がるか、平均的な熱の入り方 オイラー–オイラー法（今回の方法）
長時間（数分〜数時間）の熱変形 流れは短時間だけ解いて熱伝達率を取り出し、固体だけを長時間解く（一方向の受け渡し）

次の一手の候補：OpenFOAM 13 で、run004 と同じ加工エリアを VOF ＋ 固体連成で解き、 オイラー–オイラー法の結果（ワーク上面がほとんど温まらない）と比べる。
